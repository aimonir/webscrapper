# 🕵️‍♂️ Web Scraper - Job Listings, News, & Stocks

This is an **automated web scraper** that fetches **job listings, news headlines, and stock prices** using `BeautifulSoup` and `requests` in Python.

## 📌 Features
✅ Scrapes **job listings** (from Indeed, LinkedIn, etc.)  
✅ Extracts **latest news headlines**  
✅ Fetches **stock market data** (Yahoo Finance, Google Finance)  
✅ Saves output as a **CSV file (`data.csv`)**  
✅ Rotates **User-Agent** to bypass website blocks
